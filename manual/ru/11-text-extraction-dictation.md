# Извлечение текста и диктовка

### Извлечение текста

Нажмите `Super + Ctrl + PrtScr`, чтобы выбрать область на экране для извлечения текста. Открытая OCR-модель tesseract быстро преобразует выделенное в текст и поместит его в буфер обмена. Затем просто нажмите `Super + V` для вставки.

Это очень полезно для захвата адресов из подвалов изображений или номеров телефонов, встроенных в заголовки сайтов.

### Диктовка

На свежих установках [Superwhisper](https://superwhisper.com/) является движком диктовки по умолчанию, используя облачную обработку без скачивания офлайн-моделей. Выбрать Superwhisper или [Voxtype](https://voxtype.io/) можно через _Настройка > По умолчанию > Dictation_ в меню LunaOS. Выбор движка устанавливает его при необходимости и делает движком по умолчанию для диктовки. Voxtype загружает базовую английскую модель объёмом 150MB; модель можно изменить через `voxtype setup model`, а остальные настройки — через `~/.config/voxtype/config.toml`. Superwhisper открывает свои настройки для выбора облачной или локальной обработки, а OPR поддерживает приложение в актуальном состоянии.

Диктовать можно, удерживая `Right Alt` или `F9`, или переключая через `Super + Ctrl + X`, и надиктованный текст появится в сфокусированной области ввода. Эти сочетания используют выбранный движок. Right Alt также начинает диктовку при использовании в аккорде модификаторов; используйте Left Alt для таких аккордов. На раскладках клавиатуры, где Right Alt — это AltGr, используйте `F9`, чтобы сохранить AltGr доступным для ввода.

Те же сочетания работают с любым движком. Выбирайте движок через Setup > Defaults > Dictation. Установщик движка настраивает его и сохраняет выбор. Выполните `lunaos default dictation`, чтобы увидеть, какой выбран. Выбор сохраняется в `~/.config/lunaos/defaults/dictation`. Свежие установки автоматически выбирают Superwhisper.

LunaOS автоматически загружает интеграцию выбранного движка с рабочим столом. Никакой конфигурации Superwhisper в `~/.config/hypr/` не требуется.

Пользовательские привязки и скрипты могут использовать `lunaos dictation start`, `lunaos dictation stop` и `lunaos dictation toggle`. Выбранный движок обрабатывает запись и транскрипцию. Выбор Superwhisper отключает его нативное сочетание удержания и устанавливает его нативное переключение на `Alt + Space`, отделяя его от клавиш записи LunaOS. Superwhisper требует как минимум одно нативное сочетание записи, а его сочетание отмены остаётся доступным.

Дополнительные движки могут интегрироваться без изменения LunaOS. Предоставьте исполняемый файл с именем `lunaos-dictation-<backend>` в PATH, который принимает `start`, `stop` и `toggle` и быстро возвращает управление, с ненулевым статусом при сбое. Его установщик настраивает провайдера и вызывает `lunaos-dictation-use <backend>` после успешной настройки. Это останавливает предыдущий движок и атомарно сохраняет выбор; `stop` должен успешно завершаться, когда провайдер бездействует или недоступен. Имена движков используют строчные буквы, цифры и дефисы. Предоставьте `lunaos-install-dictation-<backend>` для настройки; `lunaos default dictation <backend>` запускает его. Добавьте пункт в меню Defaults через расширение меню LunaOS, чтобы вызывать этот селектор. Опциональная интеграция с рабочим столом может находиться в `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
