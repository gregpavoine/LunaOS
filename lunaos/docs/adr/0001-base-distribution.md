# ADR 0001: additive V0 on existing Omarchy

Accepted for Task 1, 2026-10-24. Current task and Series26 override older
from-scratch installation language. Preserve upstream Omarchy/Arch, Hyprland,
launcher, notifications, clipboard, web apps, package engine and recovery.
No macOS Omarchy install, package removal, Linux changes or SSH connection.
Custom Arch image and independent rootfs both introduce unnecessary boot risk for
this milestone. Later reproducible images remain Mont Blanc requirements, with
license attribution, inventory, selected disks and demonstrated recovery required.
No claim that this is a distribution built from scratch.
