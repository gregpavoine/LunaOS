# LunaOS 0.1.0 — First Bootable ISO

LunaOS 0.1.0 is the first x86_64 UEFI live ISO technical preview. The published image is built from the tagged source and is released only after the automated QEMU UEFI smoke check confirms that systemd reaches the graphical target.

## Scope

- Arch Linux x86_64 live image with Hyprland/Wayland and a Quickshell command-center source shell.
- Go Core and Policy Broker services with local SQLite persistence and owner-scoped local control.
- Boots as a live environment; the image is not an installer and does not provision a disk installation.
- SHA-256 checksum is published beside the ISO.

## Known limits

- The automated boot result is a QEMU UEFI smoke test, not a physical-hardware compatibility result.
- Installation to disk, upgrades, rollback, recovery, secure boot, NVIDIA/GPU acceleration, target Omarchy cleanup and real-hardware behavior are not verified by this release.
- The goal engine currently supports a bounded local checksum action; local LLM inference, general autonomous planning and the full Mont Blanc feature scope are not implemented.
- Do not treat this technical preview as a production-ready operating system or use it to replace an existing installation.
