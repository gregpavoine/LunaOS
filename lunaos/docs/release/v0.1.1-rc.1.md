# LunaOS 0.1.1 RC 1 — Installable Preview

> Superseded: this candidate was published as split ISO parts and did not pass the
> automated install-and-reboot gate. Do not use it as the clean single-file ISO.

LunaOS 0.1.1 RC 1 is an x86_64 UEFI installation preview. It adds a guided Arch Linux installation path to the existing live desktop. This is a pre-release for disposable virtual-machine evaluation, not a production operating system or a completed Mont Blanc 1.0 release.

## Download and verify

Download both `lunaos-0.1.1-x86_64.iso.part-*` files, `PARTS.sha256` and `SHA256SUMS` from the GitHub release assets into the same directory. The ISO is split because GitHub limits an individual release asset to 2 GiB. Verify the downloaded parts, reassemble the ISO and verify the complete image:

```sh
shasum -a 256 -c PARTS.sha256
cat lunaos-0.1.1-x86_64.iso.part-* > lunaos-0.1.1-x86_64.iso
shasum -a 256 -c SHA256SUMS
```

On Linux, `sha256sum --check SHA256SUMS` can be used for the final verification instead.

Use the ISO only on an x86_64 UEFI virtual machine with a disposable virtual disk. Do not select a disk containing data or an operating system you need to keep. The installer delegates partition layout, filesystem, encryption, account and bootloader choices to Arch Linux's guided `archinstall` program; some choices can erase the selected disk.

## Install flow

1. Boot the ISO in UEFI mode and choose **Install LunaOS** from the live desktop, or run `sudo -n /usr/local/bin/lunaos-install` in a live terminal.
2. Review the package plan and read-only disk listing. The installer requires the exact confirmation `INSTALL LUNAOS` before opening `archinstall`.
3. In `archinstall`, explicitly choose the disposable target disk and review its proposed layout, user account, encryption and bootloader settings before accepting the installation.
4. The installer uses packages bundled in the ISO-local repositories and runs a LunaOS finalizer inside the target system. After it returns, remove the ISO and reboot manually.

The installer does not preselect a disk or store account credentials in its configuration. The live launcher grants sudo access only to the root-owned LunaOS installer entrypoint. The installed-system finalizer configures the first interactive account for `luna-owner`, installs greetd and Hyprland defaults, enables NetworkManager and the LunaOS Core/Broker units, and removes the ISO-only package source from the installed system.

## Included

- Arch Linux x86_64 UEFI live environment using Hyprland/Wayland and the Quickshell/QML LunaOS shell source.
- Guided disk installation through upstream `archinstall`.
- An ISO-local repository containing the LunaOS package and the Arch package closure used by this profile.
- Go Core, Policy Broker, owner setup and vault binaries packaged for the installed target, with systemd service units.
- A checksum file alongside the ISO artifact.

## Verification status

The GitHub Actions build runs the Archiso image build and a QEMU/OVMF UEFI live-boot smoke test. A passing boot smoke confirms only that the image boots to the graphical systemd target and starts the first-boot credential setup, Policy Broker and Core. It does not install the OS to a virtual disk.

**Installation acceptance is not claimed by this release.** The guided installer, target finalizer, installed greetd/Hyprland session, owner socket permissions, service startup after disk installation, benign goal execution and recovery after a failed installation still require an end-to-end disposable UEFI VM run. The release page and checksums identify the exact downloadable artifact; they do not substitute for that missing acceptance result.

## Known limitations

- Preview support is limited to x86_64 UEFI. BIOS boot, ARM, Secure Boot, physical hardware compatibility, NVIDIA acceleration and power-management behavior are not verified.
- Existing OS preservation, dual-boot layouts, disk encryption policy, interrupted-install recovery, system upgrades, rollback and data recovery are not verified. Treat the selected target disk as disposable.
- The installed desktop and LunaOS systemd services have not been verified by an install-and-reboot acceptance run unless that result is separately published with the artifact.
- Local LLM inference, general autonomous planning, hardware capability claims, privacy sensor enforcement and the complete Mont Blanc 1.0 feature scope are not implemented as production-ready OS capabilities.
