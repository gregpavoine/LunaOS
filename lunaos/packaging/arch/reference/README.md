# Withdrawn Archiso prototype workflow

`legacy-lunaos-archiso.yml` is the frozen workflow for the earlier nested Archiso prototype. It is outside GitHub's active workflow directory and must not publish new LunaOS images. The former GitHub workflow was manually disabled and its old ISO artifacts were removed on 2026-10-27 at the owner's request.

Future LunaOS images belong to the separate `gregpavoine/LunaOS-iso` repository following the Omarchy-style source/package/image split. Keeping this file preserves the previous build and acceptance procedure as reference; it does not establish that an installable release is available.
